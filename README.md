# Proyecto Sprint 7: Análisis de Anuncios de Venta de Coches

Esta aplicación web, desarrollada con **Streamlit**, permite explorar de forma interactiva un conjunto de datos de anuncios de venta de coches en Estados Unidos.

## Funcionalidad

La aplicación incluye dos visualizaciones interactivas, cada una activable mediante una casilla de verificación:

- **Histograma**: muestra la distribución del kilometraje (odómetro) de los vehículos anunciados.
- **Gráfico de dispersión**: compara el kilometraje contra el precio de cada vehículo.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit

## Cómo ejecutar la aplicación localmente

1. Crear y activar un entorno virtual.
2. Instalar las dependencias con `pip install -r requirements.txt`.
3. Ejecutar `streamlit run app.py`.
