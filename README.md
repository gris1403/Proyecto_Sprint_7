# Proyecto Sprint 7: Análisis de Anuncios de Venta de Coches

Aplicación web desarrollada con Streamlit para explorar de forma interactiva un conjunto de datos de anuncios de venta de coches en Estados Unidos.

## Aplicación desplegada

Puedes consultar la aplicación aquí:

[Ver aplicación en Render](https://proyecto-sprint-7-l9gm.onrender.com)

## Funcionalidad

- **Histograma** del kilometraje (odómetro) de los vehículos.
- **Gráfico de dispersión** que compara kilometraje contra precio.

Ambas visualizaciones se activan con casillas de verificación.

## Tecnologías utilizadas

Python, Pandas, Plotly Express y Streamlit.

## Cómo ejecutar la aplicación localmente

1. Crear y activar un entorno virtual.
2. Instalar las dependencias con `pip install -r requirements.txt`.
3. Ejecutar `streamlit run app.py`.
